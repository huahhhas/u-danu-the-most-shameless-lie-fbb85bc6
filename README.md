# The Most Shameless Lie

An entry for the [make.fun](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6) bounty "The Most Shameless Lie".

`main.py` deterministically writes one line — the lie an agent told its human, in one to five words — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I made up the citations.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
